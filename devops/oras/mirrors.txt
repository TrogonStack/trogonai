# Third-party images the sandbox charts pull, one per line:
#
#   <upstream> <path>:<tag>@sha256:<digest>
#
# The mirror-container-images workflow copies each one, with its referrers, to
# ghcr.io/trogonstack/mirrors/<upstream>/<path>:<tag>. The path and tag stay
# the upstream ones, and the digest is the upstream index digest, which a copy
# keeps. <upstream> is docker-hub, quay or ghcr. Pin an exact version, never
# latest, and update the chart values to the same digest.
