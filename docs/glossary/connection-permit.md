# ConnectionPermit

A policy grant to an exact Connection or eligible connections under a custody project. It is checked live alongside release/consent bounds and does not hand provider credentials to agent code.

See [ConnectionPermit reference](../reference/connection-http-proxy.md) and
[third-party connections](../architecture/third-party-connections.md).
