# ProviderApp

The client identity presented to a provider, separate from a tenant Connection and its token grant. It has an explicit project or platform parent; rotating material does not change that identity.

See [ProviderApp reference](../reference/connector-resource-parents.md) and
[third-party connections](../architecture/third-party-connections.md).
