# ConnectionGrant

Authority for one Session execution attempt to use a planned Connection. Its parent is the Session project, which may differ from Connection custody; the supervisor proves each HTTP request.

See [ConnectionGrant reference](../reference/connector-binding-integration.md) and
[third-party connections](../architecture/third-party-connections.md).
