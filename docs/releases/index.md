# Releases

TrogonAI releases are the durable record of what is ready to consume, what is
being tested, and what changed between versions.

## Release channels

Choose a channel based on how much change you want to absorb:

| Channel | Purpose | Stability |
| --- | --- | --- |
| **Stable** | Recommended versions for production and shared environments | Supported |
| **Preview** | Early access to features that need broader feedback | Expected to change |
| **Nightly** | The latest automated build for active development | Experimental |

See [release channels](/releases/channels) for the promotion rules and the
signals each channel should carry.

## Release notes

Release notes will live here as versioned pages. Each note will describe the
user-visible changes, migration work, compatibility impact, and verification
status for that release.

There are no published version notes in this documentation snapshot yet.

## Keeping up to date

- Follow the repository releases on [GitHub](https://github.com/TrogonStack/trogonai/releases).
- Use Stable for deployments that need a supported upgrade path.
- Read the release note before promoting Preview or Nightly builds.
